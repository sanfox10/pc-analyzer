# PC Analyzer 🖥️

Know your machine. Benchmark it. Share the debug report.

## Files

| File | What it does |
|---|---|
| `index.html` | Browser check - auto specs, CPU/FPS benchmark, copyable debug report. Just double-click it. |
| `analyze.py` | Full hardware pull - CPU, RAM, disks, network, top processes. Needs `pip install psutil`, then `python analyze.py`. |

## Use it

- `index.html` works anywhere, offline, on phone or PC.
- `analyze.py` runs on your own PC only (it reads real hardware).
